### Professional Summary
Independent developer specializing in Lua 5.1 modularity and World of Warcraft UI optimization. I focus on performance-driven scripting, automated debugging, and creating clean, high-contrast user interfaces. Creator of KkthnxUI, Sentinel, and various utility-focused projects designed to enhance the gaming experience through high-performance code. Explore my complete portfolio of addons on [CurseForge](https://www.curseforge.com/members/kkthnx/projects) or visit my [Personal Website](https://kkthnx.com/).

---

### Active Development
*   **[KkthnxUI](https://github.com/Kkthnx-Wow/KkthnxUI):** A modular, performance-optimized UI framework for World of Warcraft.
*   **[Sentinel](https://github.com/Kkthnx-Wow/Sentinel):** A modern Lua error watcher that catches, deduplicates, and persists UI bugs.
*   **[NexEnhance](https://github.com/Kkthnx-Wow/NexEnhance):** A lightweight framework for modern expansion enhancements.
*   **[AuctionAgent](https://github.com/Kkthnx-Wow/AuctionAgent):** An open-source, local-first Auction House scanning utility.
